# QSkill Internship - Task 1

## Project Name
Basic Data Analysis Using Pandas

## Objective
To analyze student marks using Python and create
visualizations to understand the data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Features
1. Load CSV dataset.
2. Calculate average marks.
3. Find maximum and minimum marks.
4. Create a bar chart.
5. Create a scatter plot.
6. Create a correlation heatmap.
7. Analyze the results.

## Dataset
Student marks in Python, Java, and Mathematics.

## How to Run
Install the required libraries:

pip install pandas matplotlib seaborn

Run the program:

python data_analysis.py

## Output
The program displays statistics and generates
three visualizations.
